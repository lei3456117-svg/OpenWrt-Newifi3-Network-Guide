## 📖 项目简介
本教程记录了一次从**路由器误删组件瘫痪**到**重刷官方正式版、U盘扩容、DNS防污染配置、再到企业级网络双链路分流**的完整实战全流程。

* **硬件设备**：联想 Newifi 3 D2 (MT7621AT, 512MB RAM, 32MB Flash)
* **固件系统**：OpenWrt 25.12.5 (Linux 6.12 内核, apk 架构)
* **网络环境**：公司企业有线网 (绑定 MAC + 静态网段) + 桌面千兆交换机

---

## 🎯 核心解决痛点

1. **变砖急救**：误卸载 `dnsmasq` 导致路由器无法分发 IP 后的 Breed 官方纯净底包恢复流程。
2. **闪存瓶颈**：机身剩余 23MB 闪存无法安装现代科学上网插件，通过 U 盘进行 **Extroot 根目录扩容至 3.5GB**。
3. **DNS 深度防污染**：`dnsmasq-full` 与精简版的本质区别，以及为何防污染协议能让**便宜订阅秒开 Google Anti-gravity / Gemini / Codex**。
4. **双重代理套娃踩坑**：为什么硬路由规则无法规避客户端冲突，以及最终采用**桌面交换机物理双链路分流**的最佳实践。
5. **v2rayA 进程崩溃与 MIPS Go 运行时排障**：`v2raya-2.2.7.5-r1` 导致 2017 端口拒绝连接与 `panic before malloc heap initialized` 死循环崩溃的定位与升级修复 SOP（升至 `r2`），以及客户端同时开本地代理（Antify）导致的握手超时排查。
